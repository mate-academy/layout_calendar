# Calendar

A month calendar built with HTML and SCSS only, no JavaScript.

## Live Preview

[slysahex.github.io/layout_calendar](https://slysahex.github.io/layout_calendar/)

## Technologies Used

- HTML5
- SCSS (variables, `@for`, `@each` loops)
- BEM methodology
- Flexbox

## Features

- Day numbers generated with CSS (`::before` + `@for`), not hardcoded in HTML
- `start-day` modifier: the month can start on any day of the week
- `month-length` modifier: 28, 29, 30 or 31 days
- Animated hover effect on days (color and lift)
- Centered on the page horizontally and vertically

## Getting Started

```bash
git clone https://github.com/slysahex/layout_calendar.git
cd layout_calendar
npm install
npm start
```
